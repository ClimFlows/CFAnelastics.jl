CFAnelastics

Anelastic binary fluid in a 2D box, discretized with energy-consistent finite volumes on a C-grid, in the ClimFlows ecosystem. The source is at CFAnelastics.jl.

The model

AN2D advances the tracers $m = \rho_R (\mathrm{consvar}, q)$ at cell centers and the velocity $(u, w)$ on the faces, where $\rho_R(z)$ is a hydrostatic reference density (AnelasticReference), under the constraint $\nabla\cdot(\rho_R \mathbf{u}) = 0$. The pressure $\varphi = (p - p_R)/\rho_R$ that enforces it is found at each evaluation of the tendencies by the PoissonSolver, with impermeable walls and periodic or bounded horizontal directions.

The forcing of the momentum is chosen by a BuoyancyScheme:

schememomentum forcing
ThermodynamicForcing$-\mathrm{consvar}\,\nabla\pi - q\,\nabla\mu - \nabla B - g\hat z$, with a horizontal part
ConsistentBuoyancyalong $z$ only, $b = g(\rho_R v - 1)$
LegacyBuoyancyalong $z$ only, $b = g(1 - 1/(\rho_R v))$

Usage

using CFAnelastics, CFBoxes, CFDiffusionSchemes, CFTimeSchemes, ClimFluids
using CFPlanets: Tank2D
using LoopManagers: MultiThread, VectorizedCPU

space = Tank2D(Lx = 1.0, Lz = 0.5, g = 10.0)
fluid = NonlinearBinaryFluid(:potential_temperature, (; p0 = 1e5, T0 = 280.0, q0 = 0.035, Cp0 = 4000.0, v0 = 1e-3,
    α_T = 2e-4, α_q = 0.8, α_p = 1e-6, M_s = 3.14038218e-2, R = 8.31446261815324, α_TT = 1e-5, γ = 1e-7))
domain = Box2D(; Mx = 32, Mz = 16, boundary = (Periodic, Bounded))
wall = Wall(tangential = FreeSlip(), tracers = (Flux(0.0), Flux(0.0)))
model = AN2D((; mgr = MultiThread(VectorizedCPU()), domain, space, fluid,
    spatial_scheme = Centred2(), vortex_scheme = VortexEnergyCons(), buoyancy_scheme = ThermodynamicForcing(),
    thermoflux_scheme = ThermoFluxConsistent(k_T = 1e-4, k_q = 1e-5), viscosity_scheme = ViscosityScheme(dyn_visc = 1e-3),
    anelastic_reference = AnelasticReference(domain, space, 1000.0; pref = 1e5),
    boundary_conditions = BoxBoundaryConditions(domain; bottom = wall, top = wall), gauge_offset = 0.0))

state = CFAnelastics.initialize(model; consvar = (x, z) -> 280 + z / 0.5 + 0.3 * sin(2π * x), q = (x, z) -> 0.035)
state = CFAnelastics.loop(state, model, CFTimeSchemes.RungeKutta4(model),
                          (; Nslice = 2, slice_size = 1.0, dt_max = 0.1, cfl = 0.8))

The tendencies are CFTimeSchemes.tendencies!(dstate, scratch, model, state, t), which returns (dstate, scratch); both are allocated when void, and the call does not allocate once they are.

CFAnelastics.CFAnelastics — Module
CFAnelastics

Anelastic binary fluid in a box: the AN2D model (AN2D), its reference state (AnelasticReference), the Poisson solver for its pressure (PoissonSolver) and its momentum forcing (BuoyancyScheme).

source
CFAnelastics.AN2D — Type
model = AN2D((; mgr, domain, space, fluid, spatial_scheme, vortex_scheme, buoyancy_scheme, thermoflux_scheme,
                viscosity_scheme, anelastic_reference, boundary_conditions, gauge_offset))

Anelastic binary fluid in a 2D box (x, z): prognostic m = ρR (consvar, q) at cell centers and the velocity (u, w) on faces, with ∇·(ρR u) = 0. spatial_scheme (e.g. Centred2()) sets the interpolations and differences of the C-grid, vortex_scheme the vortex force, buoyancy_scheme the momentum forcing (see BuoyancyScheme). gauge_offset [m² s⁻²] is the constant added to the kinematic pressure φ = (p - pR)/ρR, defined up to a constant: the horizontal mean of φ on the bottom level is gauge_offset (see PoissonSolver). It changes the pressure but no tendency.

source
CFAnelastics.AnelasticReference — Type
reference = AnelasticReference(domain, space, ρ; pref)

Reference state of the anelastic model on the grid of domain spanning space, along the full z axis (halo included): the density ρ_R and the hydrostatic pressure p_R at cell centers, with ∂pR/∂z = -g ℑz(ρR) discretely (the density of the w-face between two cells is their average, as in the model). The pressure is anchored at the height space.z0 where the geopotential vanishes: pref [Pa] is the value at z0 of the piecewise-linear interpolant of the cell-center pressures (extrapolated linearly from the two nearest interior cells if z0 is outside the box). The density ρ [kg m⁻³] is a number, a function ρ(z) of the height z above the bottom, or a vector of its values in the Mz cells, from bottom to top (extended by its end values into the halo). Face values and the specific volume are computed where needed: ρ_R on w-faces is the average of the two cells.

CFAnelastics.PoissonSolver — Type
solver = PoissonSolver(domain, spacing, ρ_R; gauge_offset = 0, flags = FFTW.MEASURE)

Poisson solver for the anelastic pressure on a Box2D or Box3D, with grid spacing (dx, dz) or (dx, dy, dz) in m. The vertical direction must be bounded; horizontal directions may be periodic or bounded, following the box topology. ρ_R (kg m⁻³) is the reference density at cell centers along the full z axis, halo included. flags are the FFTW planner flags: FFTW.MEASURE times candidate algorithms at construction and keeps the fastest, so results may differ at round-off level between runs; FFTW.ESTIMATE plans at once, reproducibly, with slower transforms. gauge_offset [m² s⁻²] is the constant added to the solved φ (see pressure!). Apply with pressure!.

The tridiagonal system of a row of modes_by_level (horizontal eigenvalue λ) at level j = 1, …, Mz (interior levels) reads

a_j φ_{j-1} + b_j φ_j + c_j φ_{j+1} = r_j,
a_j = ρ_w(j - 1/2) / Δz²  (0 at the bottom wall),   c_j = ρ_w(j + 1/2) / Δz²  (0 at the top wall),
b_j = λ ρ_R(j) - a_j - c_j,

and is solved by the Thomas algorithm, with pivots p1 = b1, pj = bj - aj c{j-1} / p_{j-1}:

forward elimination:   y_1 = r_1 / p_1,   y_j = (r_j - a_j y_{j-1}) / p_j,
back substitution:     φ_Mz = y_Mz,       φ_j = y_j - (c_j / p_j) φ_{j+1}.

Fields:

  • domain: the box
  • inv_spacing: (1/Δx, 1/Δz) or (1/Δx, 1/Δy, 1/Δz) [m⁻¹]
  • gauge_offset: constant added to φ after the solve, the gauge of the pressure [m² s⁻²]
  • ρ_R: reference density at cell centers, full z axis (halo included) [kg m⁻³]
  • ρ_w: reference density on w-faces, ℑ(ρ_R), full z face axis [kg m⁻³]
  • rhs: interior cells (Mx[, My], Mz): r/scale before the forward transform, φ after the backward one
  • modes: the transform coefficients of each level, as real numbers, last dimension the level. With a periodic direction they are complex and stored with real and imaginary parts interleaved along the first dimension, of size (2 × first coefficient count, other coefficient counts…, Mz); otherwise (Mx[, My], Mz) cosine coefficients
  • spectral: modes as the transforms see it: complex numbers (a reinterpretation of the same memory), or modes itself when no direction is periodic
  • modes_by_level: the same memory as modes, seen as (row, level): each row, a real or imaginary part of one coefficient, is one tridiagonal system
  • forward_plan: transform of one level, rhs → spectral: r2c along the periodic directions, or DCT-II along all directions when none is periodic
  • forward_cosine_plan: in place on one level of spectral: DCT-II along the bounded directions, after the r2c; nothing when no direction is bounded or none is periodic
  • backward_cosine_plan: in place, the inverse of forward_cosine_plan up to its normalization (DCT-III), or nothing
  • backward_plan: one level, spectral → rhs, the inverse of forward_plan up to its normalization: c2r (which overwrites its input), or DCT-III
  • scale: backward ∘ forward = scale × identity
  • sub_diagonal: a_j per level [kg m⁻⁵]
  • thomas_factor: cj / pj per (row, level)
  • inv_pivot: 1 / p_j per (row, level)

  • model: AN2D model instance
  • state: initial state (see initialize), overwritten by the final state; copy it first to keep it
  • time_scheme: time integration scheme
  • params: (; Nslice, slicesize, dtmax, cfl): Nslice time slices of slice_size [s], each split into equal steps of at most dt_max [s] and cfl (≤ 1 for stability) times the stability limit of time_scheme, see cfl_condition
  • outputs: callable outputs(model, state, dstate, scratch, book, t), called at t = 0 and at the end of each time slice, with the diagnostics book and the time t [s]; e.g. to record diagnostics, then closed with close(outputs) when the run ends, even on error; nothing records nothing
  • book: the diagnostics CookBook handed to outputs, e.g. one with more diagnostics than diagnostics(model); built once, as each session of it overwrites the same output arrays

CFAnelastics.max_buoyancy_frequency — Method

max(N) [s⁻¹] over the w-faces J between interior cells J-1 and J, N² = g (α ∂consvar/∂z - β ∂q/∂z), with α = ∂v/∂consvar / v and β = -∂v/∂q / v at the face (mean reference pressure, consvar and q of the two cells); N² < 0 (static instability) does not oscillate and gives 0.

CFAnelastics.max_frequency — Method
ω = max_frequency(model::AN2D, state)

Return an upper bound ω [s⁻¹] on the fastest discrete frequency of the state over the interior, the sum of:

  • advection, centered on the C-grid: max|u|/dx + max|w|/dz;
  • diffusion: 4 max(ν, kT, kq) (1/dx² + 1/dz²), with ν = (4μ/3) / min(ρ_R), the compressive modes being damped by (4μ/3) ∇(∇·u);
  • internal gravity waves (ω = N |kₓ|/|k| ≤ N): max(N), see max_buoyancy_frequency.

CFAnelastics.pressure! — Method
pressure!(φ, solver::PoissonSolver, mgr, dU)

Solve for the modified pressure φ = (p - pR)/ρR (m² s⁻², cell centers, halo included) such that dU - ∇φ satisfies the discrete anelastic constraint ∇·(ρR (dU - ∇φ)) = 0 with no flow through walls, dU = (du, dw) or (du, dv, dw) being the momentum tendencies on faces (m s⁻²), periodized in periodic directions. Sets the normal components of dU on wall faces to zero. Fills the halo of φ: periodic, or zero normal gradient on walls. The horizontal mean of φ on the bottom level is `gaugeoffset(zero by default): φ is defined up to a constant, which changes no tendency. Returnsφ`.
